# killer sudoku solver

агент для автоматичного розв'язання головоломок кілер-судоку
агент формалізує гру як задачу задоволення обмежень і використовує алгоритм пошуку з поверненням, підсилений евристиками та математичним відсіканням для оптимізації експоненційного дерева пошуку

## ынтелектуальні особливості алгоритму

*   **CSP:** модель середовища жорстко контролює правила класичного судоку  та специфічні правила кілер-судоку
*   **(MRV):** замість наївного перебору агент використовує евристику MRV, на кожному кроці він сканує дошку і обирає клітинку з найменшою кількістю доступних легальних варіантів, що кардинально зменшує фактор розгалуження
*   **відсікання:** агент застосовує математичне відсікання, якщо поточна сума клітки плюс теоретично максимально можлива сума для решти порожніх клітинок не дозволяє досягти цільового значення, гілка пошуку миттєво відкидається

## структура проєкту

*   `killer_sudoku.py` — модель середивища, зберігає стан дошки, парсить JSON та перевіряє валідність дій
*   `solver.py` — агент, містить рекурсивний алгоритм пошуку за допомогою бектрекінгу та евристику MRV
*   `main.py` — GUI на базі `tkinter`, візуалізує сітку, клітки та відображає статистику
*   `puzzle.json` — Файл конфігурації головоломки. сістить координати кліток та їхні цільові суми.
*   `test_sudoku.py` — содуль юніт-тестування логіки середовища та агента

## запуск та використання

потрібен лише пайтон без додаткових бібліотек. треба просто запустити main.py
